# Technologies Used

## Frontend

### HTML
Used to create the structure of the PocketSmart AI web application.

### CSS
Used to design the dashboard, forms, buttons, cards and tables.

### JavaScript
Used to handle user input, calculations, transactions and recommendations.

## Backend

### Python
Used for backend development and recommendation functionality.

### Flask
Used to create the backend API.

## Recommendation System

A rule-based recommendation system is used to compare expenses with the monthly budget and provide spending recommendations.

## Database

A database schema is designed to store:

- Income
- Expenses
- Budget
- Transactions

## Development Platform

GitHub is used to store and manage the project source code and documentation.

# Phase 8 – Project Demonstration

## Project Name

PocketSmart AI – Your Smart Budget & Recommendation Assistant

## 1. Project Overview

PocketSmart AI is a smart budget and recommendation assistant that helps users manage their income, expenses and monthly budget.

## 2. Purpose of the Project

The purpose of PocketSmart AI is to provide a simple application for tracking financial information and understanding spending behaviour.

## 3. Key Features

- Add and track income
- Add and track expenses
- Set monthly budget
- Calculate remaining balance
- View recent transactions
- Generate budget recommendations
- Simple and user-friendly dashboard

## 4. Demonstration Process

During the demonstration, the following steps will be shown:

### Step 1 – Open Application

Open the PocketSmart AI application and display the dashboard.

### Step 2 – Add Income

Enter an income amount and select the income source.

### Step 3 – Add Expense

Enter an expense amount, category and description.

### Step 4 – Set Monthly Budget

Enter and set a monthly budget.

### Step 5 – View Dashboard

Show the total income, total expenses, remaining balance and monthly budget.

### Step 6 – View Transactions

Show the income and expense transactions in the Recent Transactions section.

### Step 7 – View Recommendation

Show the PocketSmart AI recommendation based on the budget and expenses.

## 5. Benefits

- Easy financial tracking
- Simple budget management
- Quick expense monitoring
- Automatic balance calculation
- Useful spending recommendations

## 6. Technologies

- HTML
- CSS
- JavaScript
- Python
- Flask
- Rule-based recommendation logic

## 7. Final Output

The final output is a working PocketSmart AI budget management application with a dashboard, transaction tracking and spending recommendations.
